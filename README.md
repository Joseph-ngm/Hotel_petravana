# Hotel_petravana
Application de gestion des recettes (revenus) d’un hôtel, conçue autour de deux acteurs : le commis, qui saisit, modifie, annule, supprime, enregistre et transmet les recettes, et le PDG, qui valide les recettes et approuve ou désapprouve les demandes de modification, d’annulation et de suppression du commis.
